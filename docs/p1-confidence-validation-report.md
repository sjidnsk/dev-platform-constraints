实验结论：

- 三组配置均通过数据契约与路径验证，路径节点数均为 `32`，说明当前可信度权重消融不会破坏 P0/P1 最小闭环。
- 权重变化对当前样例路径影响很小；路径总代价最大差异约为 `0.11%`，且低可信高风险路径比例均为 `0.0`，表示当前路径没有穿越低可信高风险区域。
- `consistency_recency_focused.json` 当前表现最好：更新后平均可信度最高，平均可信度下降最少，`ΔC` 比默认配置高约 `226.9%`，路径总代价也最低。
- `observation_focused.json` 当前不适合作为默认策略：相比默认配置，`ΔC` 下降约 `52.7%`，更新后低可信区域面积增加到 `10.0`。这表明在当前简化距离/FOV 观测模型下，单纯提高观测权重不一定带来更高综合可信度。
- Top-3 探索目标在三组配置下完全一致，说明当前目标排序主要由 `value`、可达性和局部风险结构主导；可信度权重变化尚不足以改变目标优先级。

推荐结论：下一轮实验优先使用 `consistency_recency_focused.json` 作为 P1/P2 探索基线，保留 `default.json` 作为对照；`observation_focused.json` 仅用于观测模型增强后的再评估。

局限性：当前结果来自单一确定性样例地图、单一起终点和一次局部观测。后续应增加不同观测位姿、目标点、地图尺寸、低可信区域分布和价值图分布，验证上述结论是否稳定。
